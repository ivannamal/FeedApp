# FeedApp

A social feed iOS app built with UIKit, MVVM and Coordinator navigation.

- Sign in with token auth, token stored in the Keychain
- Paginated feed on a diffable data source with pull-to-refresh
- Async image loading with in-memory caching, safe against cell reuse
- Profile screen and sign out

Sources only - the generated API client is not included.

Min iOS 17, Swift, UIKit, async/await.
